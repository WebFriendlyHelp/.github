# Web Friendly Help LLC

Web Friendly Help is an assistive technology business for blind and low-vision people, run by Casey Mathews, who is blind. The software here is built and tested with a screen reader every day, by the person who needs it to work.

## Projects

- [KeyQuest](https://github.com/WebFriendlyHelp/KeyQuest): a typing adventure game for Windows with screen reader, keyboard, and low-vision support. Free and open source.
- [Text Marks the Spot](https://github.com/WebFriendlyHelp/TextMarksTheSpot): an NVDA add-on that moves the browse cursor to where a web page's real content starts. Free and open source, and available in the NVDA Add-on Store.
- [ACE, the Accessible Conversation Extractor](https://github.com/WebFriendlyHelp/ACE): read and archive your iPhone messages with a screen reader. A paid Windows program; this repository holds the downloads, release notes, and issue tracker.

## Getting help

Each project's issue tracker is the place for bugs and requests. For anything else, email help@webfriendlyhelp.com or visit [the Web Friendly Help website](https://webfriendlyhelp.com).

Accessibility statements, the code of conduct, and the security policy for these projects are in [the organization's .github repository](https://github.com/WebFriendlyHelp/.github).
