# Security Policy

This is the default security policy for Web Friendly Help LLC repositories. A repository with its own SECURITY.md follows that file instead.

## Supported versions

Only the latest released version of each project gets security fixes.

## Reporting a vulnerability

Do not open a public GitHub issue for a suspected security problem. Report it privately by email instead:

- help@webfriendlyhelp.com

Helpful to include:

- which project and version
- a short summary of the issue
- steps to reproduce, if known
- impact
- any suggested mitigation

If you are not sure whether something is a security issue or a regular bug, report it privately first.

## What happens next

I will acknowledge the report, decide whether it is in scope, and coordinate a fix or mitigation if it is confirmed. This is a one-person shop, so response times vary. Good-faith reports are appreciated.

## Disclosure

Please give me time to ship a fix before sharing details publicly.
